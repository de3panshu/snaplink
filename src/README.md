### URL Shortening Service (Spring Boot Backend)
SnapLink is a powerful and extensible URL shortening service built with Spring Boot. It allows users to convert long URLs into short, shareable links and provides the foundation for advanced features such as link analytics, promotional redirection pages, affiliate tracking, custom branding, and monetization.

>[!NOTE]
> **🔐 Guest User Support** - SnapLink allows unauthenticated users to create short links using pre-defined GUEST_USER behind the scenes (used by frontend).
